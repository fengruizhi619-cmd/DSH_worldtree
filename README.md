# dsh-naotu —— 脑图：DSH 记忆系统插件

> 原名「世界树」（DSH_worldtree），2026-11 更名。

DeepSeek Harness（DSH）的长期记忆系统插件。一条链路讲完它做的事：

1. **蒸馏入库**——会话上下文被压缩时，自动读取压缩区间、LLM 分片提炼成结构化知识条目（元事件）写入本地 SQLite；
2. **睡眠定盆**——每条元事件按句拆成句级元记忆，向量化后在 kNN 图上做梯度下滑，落入的吸引盆即「脑区」——入库即组织，无需人工挂载；
3. **赛马注入**——后续会话里用三通道（语义 + 词面 + 会话血缘）融合检索，经两级赛马池与快慢双轨决定把哪些记忆、在什么时机注入回上下文，并带时间戳与久远提示。

## 组成

```
core/                        树核（Python + SQLite，纯标准库）
├── naotu.py                 主体：元记忆/睡眠/脑区/race 三通道/全部 op 协议
├── checkpoint.py            五档稀释检查点
├── mem_attribution.py       记忆归因
├── worldtree.py             兼容 shim → naotu.py（旧脚本迁移期）
└── backfill_*.py 等         一次性维护脚本（向量回填/重打标/碎片治理）

plugin/dsh-naotu/            DSH 插件本体
├── lib/impl.mjs             P3 蒸馏管线 / 注入池赛马 / bili 双轨 / HTTP 服务
├── lib/client.js            管理面板：脑图地形 / 睡眠 / 入库 / 设置
├── lib/main.mjs             装载入口
├── helper/wiki_store.py     wiki 条目存取（只读消费 v1 的 liubian.db）
└── cordis.patch.yml         宿主装配补丁
```

## 安装

插件按 `../../core/` 相对路径引用树核，需保持本仓库目录布局：clone 后把 `plugin/dsh-naotu/` 装配进 DSH 插件目录体系（或用 profile link），`core/` 留在同级相对位置。

- 树库数据落 `data/naotu.db`（首次运行自动建表；路径可在面板「设置」中配置）
- 用户配置在 `~/.dsh/naotu/`（config.json / 注入池 / 睡眠缓存 / 提炼续传队列；由旧 `~/.dsh/worldtree` 自动迁移）

## 依赖

- **内置向量化服务**：自托管 llama-server（Qwen3-Embedding-0.6B Q4_K_M，端口 8082），自动探活 / 接管 / 拉起 / 看门狗。需自备 llama-server 可执行文件与 GGUF 模型；服务不可用时词面/血缘通道优雅降级
- **LLM 提炼/重排 API**：任意 OpenAI 兼容端点（蒸馏与注入重排闸共用，面板可配）
- wiki 库 liubian.db：`helper/wiki_store.py` 只读消费，不含于本仓库（自 v1 迁移，路径可配）
- DSH Desktop 运行环境（cordis 4 / dsh-tools）

## 主要机制

### 入库：P3 管线
监听会话压缩事件 → 压缩区间直读（保新弃旧，默认 33 万字符上限可配）→ 分片 LLM 提炼 → 入树。exists 去重、失败落盘续传、看门狗防挂起；bili 双轨（自托管 billion-context 压缩块）作为第二捕获源，血缘指纹防双轨重复蒸馏。

### 组织：睡眠与脑区
每个元事件的句子各自嵌入，在 kNN 图上从起点沿最相似邻下滑至局部极大，落入同一吸引盆的句子构成一个脑区；区名由成员事件标题票选（垃圾盆自动过滤），面板上以 `#0001` 式十进制编号标识，支持手动改名（持久化 region_alias 表）。面板「脑图」视图按脑区元记忆数做圆填充地形，检索命中区整块点亮。

### 检索与注入：三通道赛马 + 快慢双轨
- **三通道打分**：语义余弦 S（归一化）+ 词面 K（n-gram 标签重合/词面命中取大）+ 会话血缘 B，加权求和；单通道缺席自动降级
- **慢轨（两级赛马池）**：预热池（每轮检索入池打批次、加热）→ 结算晋预备池 → 周期末幸存者整头补回 + 命中补漏（≤3 条）
- **快轨（滑窗直注）**：近几轮提问向量的滑动均值实时检索，总分过线（双口径，默认 1.2）当轮直注，免两拍等待
- **护栏**：防重复注入三层闸（生命周期 / 上下文短锚 / 晋升去重）；LLM 重排闸只挂在注入路径（8s 超时、失败降级原序）；注入条目带 `时间 YYYY-MM-DD`，距今超阈值（默认 30 天）附久远可信度提示
